# Lesson Plans

Lesson plans live here as markdown files, one file per topic.

- **Authoring** — the big model (Kimi) writes the plan: "Five, make a lesson
  plan for the french revolution." Saved as `<slug>.md` here.
- **Teaching** — the local model walks through the active plan one section at
  a time, with a check question per section: "start the lesson",
  "start lesson on french revolution".
- **Managing** — "list lessons", "end the lesson".

Files are plain markdown — feel free to hand-edit or drop in your own plans;
any `# Title` heading followed by numbered sections with `Check:` questions
works.
